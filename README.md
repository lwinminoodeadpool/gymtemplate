# Gym Frontend (React + Tailwind)

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

## Features implemented

- Monthly and yearly gym subscription cards
- Personal trainer hiring cards with part-time and monthly pricing
- Class booking section (Yoga, Zumba, Weight Training) with date/time and fees
- Accessories shop (protein and gym gear)
- Responsive layout for mobile and desktop
- Live checkout summary with estimated total
